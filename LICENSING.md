# JANUS MACHINE MARKET — Licensing Boundary

The repository-level `LICENSE` is **Apache License 2.0**.

It applies to the JANUS MACHINE MARKET marketplace implementation, schemas, protocol artifacts and original documentation in this repository unless a file states otherwise.

It does **not** automatically license anything merely referenced, discovered, indexed, offered, routed or linked by the market.

```text
MARKET IMPLEMENTATION / SCHEMAS / PROTOCOL
→ Apache-2.0

LISTED JANUS PRODUCT / SERVICE
→ product-specific declared terms

JANUS HELIOS CORE / PILOT
→ canonical HELIOS terms

THIRD-PARTY DATASET / MODEL / SOURCE CODE / MEDIA
→ source license and applicable rights

DISCOVERED PUBLIC CONTENT
→ discovery does not create redistribution authority
```

## No license laundering

A product entry appearing inside an Apache-2.0 catalog does not convert the underlying product into Apache-2.0.

The following inference is invalid:

```text
LISTED_IN_APACHE_MARKET != APACHE_LICENSED_PRODUCT
```

Each product contract must declare its own licensing authority or explicitly state that a quote/agreement is required.

## Service outputs

Rights in generated service outputs depend on the governing SKU, source material and applicable third-party terms. A receipt can prove what JANUS returned; it does not erase upstream copyright, database, model, privacy, export, contract or other legal restrictions.

## HELIOS

`HELIOS.PILOT` is a delegated discovery listing only. JANUS MACHINE MARKET does not issue HELIOS licenses, modify HELIOS terms, transfer HELIOS Core, or override the canonical HELIOS Pilot Authority.

## Future machine purchase

Any future automatic purchase route must bind the exact product terms or license version into the purchase grant before execution. A payment without that bound grant creates no license.
